# Compass by Vavy Web

The public launch website for Compass by Vavy.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
```

## Cloudflare Workers preview

```bash
npm run preview
```

## Deploy to Cloudflare Workers

```bash
npm run deploy
```

The repository uses the Next.js App Router and the Cloudflare OpenNext adapter.
